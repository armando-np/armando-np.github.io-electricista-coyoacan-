FOTOGRAFIAS REALES DE TRABAJOS

Esta carpeta se deja preparada para agregar evidencia propia sin inventar proyectos.

Recomendaciones:
1. Usa archivos WebP o AVIF de 1200 px de ancho aproximadamente.
2. Nombra cada archivo de forma descriptiva: centro-carga-coyoacan-01.webp.
3. Elimina direcciones, rostros, placas y datos del cliente.
4. Incluye texto alternativo que describa lo visible, sin saturar palabras clave.
5. Crea una ficha breve con problema, solución y zona general; no publiques datos privados.
6. Comprime las imágenes antes de subirlas para mantener buen rendimiento.
